# Changelog

All notable changes to this project will be documented in this file.

## [9.0.0] - 2026-08-05

### Added
- 96 built-in cleaners (was 24, +300%)
- 4-tier confidence system (SAFE/RECOMMENDED/SUGGESTED/ASK)
- Similar file detection (duplicates, corrupted, wrong extensions)
- Piracy detection (keygens, cracks, activators)
- Version detection (old installers)
- Cleanup plans (scan once, clean multiple times)
- Data migration strategy (C: → D:)
- Interactive TUI interface
- User-friendly output mode (`--friendly`)
- Chinese app support (Baidu, WeChat, QQ, etc.)
- Gaming platform support (Steam, Epic, GOG, EA, Ubisoft)
- Office software support (Microsoft Office, LibreOffice, Thunderbird)
- Media tool support (VLC, Spotify, iQiyi, Bilibili)
- Deep scan (.bak, .DS_Store, Thumbs.db, node_modules, venv)
- Windows integration (recent docs, Windows.old, delivery optimization)
- Downloads folder analysis
- Config validation
- Parallel scanning support

### Changed
- Improved SKILL.md with better documentation
- Improved README.md with SEO optimization
- Added user-friendly explanations for each cleanup item

### Fixed
- Various bug fixes and improvements
